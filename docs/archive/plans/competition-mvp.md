# 대회용 최소 구현 순서

> 과거 기록입니다. 당시 계획·검사·제약을 보존하며, 현재 상태는 [구현 상태](../../current-state.md)를 기준으로 확인하세요.

목표 시연은 **제보 → 현재 관측과 대조 → 안내·보류·조사·작업 선택 → 검증된 사건 기록 → 다음 유사 제보에서 재확인**이다. 이 문서는 [제품 전체 로드맵](../../design/roadmap.md)보다 작은 대회 구현 순서다. 각 단계가 끝나기 전에는 다음 단계의 능력을 구현 완료로 설명하지 않는다.

| 단계 | 만들 것 | 완료 증거 |
| --- | --- | --- |
| **1. 제보와 관측 연결** | 한 프로젝트의 제한된 사건 목록에서 요청 ID 정확 일치, 또는 시각·환경·메서드·경로의 단일 후보 검색. 기존 규칙 판정으로 안내·추가 조사·작업 후보·정보 요청을 구분 | 잘못 보고한 HTTP 상태에 휘둘리지 않고, 0건·복수 후보를 보류하는 CLI와 테스트. **현재 완료: 로컬 JSON 재생만** |
| **2. 자연어·사진 접수와 프로젝트 조사** | 거친 증상·지시·사진, 규칙 빠른 판정, 제한된 조사, 같은 세션 답변, 등록 로그 범위와 버전 출처 | **통합 구현·합성 검사 완료, 실자료 게이트 미완료:** 네 라우팅·로그 범위·수동/실행 SHA 분리·종료 상태를 검사했다. 기존 NVIDIA 성공 기록 재사용. 실제 Agolive 로그/배포 연결과 실사건 검증은 남아 있음 |
| **3. 사건 기억** | 실행·최소 기록을 SQLite에 보존하고 승인/수정 검토된 카드만 정확 필드·FTS5로 검색. 과거 카드는 조사 단서로 제시하고 현재 로그·버전 출처를 다시 확인 | **로컬 구현·합성 검사 완료:** 재연결 후 실행 조회/답변, 검토·검색·현재 재확인, 반복 422와 현재 500/다른 예외·충돌 구분. 기존 127+신규 30개 통과. 검색 시간은 실측했으나 응답 시간/호출 절감과 실사건 검증은 미입증 |
| **4. 한 가지 검토 가능한 수정** | 등록한 신뢰 가능한 씨드 개발 대상의 A2 사본에서 수정 전 실패, 실제 Nemotron 제안·파일 diff, 동일 검사·회귀를 기록 | **씨드 1개 완료:** 실제 요청 키 diff, 종료 1→0/회귀 3개 통과, 원본 보존, `CHANGE_PREPARED/WAITING_REVIEW`. 첫 모델 형식 거절도 보존. OS/OpenShell 격리·실사건·원본 적용·배포는 미검증/미실행 |
| **5. 비교 평가와 제출** | 동일 자료를 준 규칙 파이프라인·수동 코딩 에이전트와 시간, 잘못된 확정, 보류, 조치 검증을 비교. 필수 NeMo Microservices 활용을 실제 기능과 호출 기록으로 제시 | 재현 명령·입력·근거·도구 호출·검증 결과와 한계. OCR 마이크로서비스 실제 호출은 2단계에서 확보 |

처음부터 다중 조직, 자동 배포, 벡터 DB, 범용 코딩 에이전트, 새 마이크로서비스 군을 만들지 않는다. 1단계의 `WORK_CANDIDATE`는 **작업이 필요해 보인다는 라우팅**이며 에이전트 실행이나 수정 완료가 아니다. 1단계 사건 목록은 사용자가 명시적으로 제공한 로컬 자료이며 운영 로그 연결이나 영속 저장이 아니다.

## 1단계 사용

```powershell
.\.venv\Scripts\python.exe -m scripts.triage_report --events examples/report_events.json --report '회원가입 API에서 500 requestId=contract-001'
.\.venv\Scripts\python.exe -m scripts.triage_report --events examples/report_events.json --report 'POST /api/users에서 500 오류' --environment dev --occurred-at '2026-09-28T10:01:00+09:00'
```

입력 JSON은 `project_id`와 최대 100개의 `events`를 가지며 전체 1 MB 이하다. 각 사건은 기존 단일 [로컬 묶음](../../../examples/backend_incident.json) 형식에 시간대가 있는 `trace.occurred_at`을 더한다. 요청 ID가 있으면 정확 일치를 사용한다. 없으면 발생 시각 ±5분·환경·메서드·경로가 모두 일치하는 **한 후보**만 임시 연결하고 추가 확인으로 보낸다. 제보의 HTTP 상태는 검색 조건으로 쓰지 않는다. 샘플 목록은 합성 자료다.

2단계의 제보자는 이 구조화된 항목을 필수로 입력하지 않는다. [자연어·사진 접수](../stages/multimodal-intake.md)에서 먼저 조사하고, 필요한 경우 화면·동작·대략적인 시각을 질문한다.

2026-09-28 직전 검토는 [1·2단계 검토 결과](../stages/stage-1-2-review.md), 계약·127개 회귀와 실제 연결 한계는 [접수·판정 통합 결과](../stages/stage-2-integration.md), 후속 SQLite 구현·157개 회귀와 날짜 보완 후 170개 기준은 [3단계 사건 기억](../stages/stage-3-memory.md)에 있다. [4단계 결과](../stages/stage-4-change.md)는 등록 씨드만 허용하는 작은 작업자와 실제 모델 호출·후보 검증 기록이다. 실제 로그·배포·사건 자료가 없어 2단계 실프로젝트 조사와 3단계 실사건 검증을 완료로 표시하지 않는다. 4단계 보고로 종료하며 비교 평가·제출 단계는 시작하지 않았다.
