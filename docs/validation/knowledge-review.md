# 사건 지식 검토·답변 비교 검증

2026-09-30. 대상 앱이나 NVIDIA 서비스에 접속하지 않고 격리된 합성 프로젝트에서 검토 대기열과 기억 끔/켬 답변 비교를 확인했다. **전체 회귀 787개 통과(307.03초), 실패·오류·건너뛰기 0개**이며 실제 PostgreSQL을 포함한다. 최종 전체 회귀·소스 해시·평가 산출물 해시는 [메타데이터](knowledge-review.json)에 기록한다.

## 검토 대기열

- 소유자 전용 API는 프로젝트별 `PENDING`·`APPROVED`·`EDITED`·`REJECTED` 카드를 제한된 요약으로 반환한다. 실행기 자격 증명과 다른 프로젝트 요청은 접근할 수 없다.
- 화면에서 저장된 판단·다음 조치·원인/후보/회복 기록 상태를 확인하고 결과 라벨·근거 메모를 선택한다. 화면은 승인 전 현재 자료·적용 범위 확인을 요구한다.
- 승인/제외와 검토 revision 충돌을 SQLite와 실제 PostgreSQL에서 확인했다. 등록된 서비스 회복 기록 없이 `RECOVERY_VERIFIED`로 표기하는 요청은 거절한다. 승인 카드는 검색에 들어가고 제외하면 검색 결과에서 빠진다.
- 기존 API의 결과 라벨 없는 승인 호출은 호환하되 `UNLABELED_LEGACY`로 남긴다. 새 화면의 라벨은 담당자 판단이며 현재 사건의 관측 근거로 승격하지 않는다.

관련 검사 **94개 통과(50.40초)**에는 기존 사건 저장·공개 자동 회복·고정 평가·실제 PostgreSQL의 새 검토 계약이 포함됐다. 실제 `daily-local`의 카드와 정책은 수정하지 않았다.

마지막 테스트 보완과 문서·패키지 갱신 후 신규 검토·PostgreSQL·제출 초안 전용 **6개 검사도 통과(6.09초)**했다. 문서 링크 496개와 Python 파일 132개 점검에서 누락·구문 오류가 없었다.

닫힌 고급 설정에서 불필요한 카드 API 조회를 피하도록 **사건 카드 불러오기**로 지연 로드한 뒤 화면·제출 초안 전용 **5개 검사도 통과(5.12초)**했다.

검토용 DRAFT 묶음에는 새 화면·평가 명령·검증 문서가 포함됐고 로컬 DB·인증·`output/`은 제외됐다. 설치용 wheel에 새 UI 모듈과 평가 코드가 포함됐다. 전용 PostgreSQL의 잔여 생성 테스트 DB 0개를 확인하고 클러스터를 종료했다.

## 답변 품질 비교

전용 명령은 기존 고정 12건을 기억 끔/켬으로 같은 자료·실행 범위·출처에서 짝지어 실행하고 `response-quality.json`을 만든다. 잘못된 안내, 근거 없는 원인·해결 확정, 필요한 추가 질문, 과거 카드 검색, 모델 호출과 합성 실행 시간을 사례별로 기록한다. 출처나 기대 결과가 다른 실행은 짝으로 세지 않는다.

| 경로 | 기억 끔 | 기억 켬 | 해석 |
| --- | ---: | ---: | --- |
| 오프라인 규칙·조사 | 고정 검사 10/12 | 고정 검사 10/12, 검색 11건 | 2건씩 미통과; 개선 효과 미입증 |
| 명시적 모델 더블 | 고정 검사 12/12 | 고정 검사 12/12, 검색 11건 | 판정 개선·악화 각 0건; 외부 모델 호출 0회 |

기존 일반 평가 명령은 예상된 시간 초과 실행도 `FAILED`로 보존하므로 실패 종료 코드를 냈다. 전용 `scripts.evaluate_response_quality --mode doubles`는 고정 답변 검사 12쌍이 모두 통과하면 성공 종료한다. 두 경로 모두 `memory_effect=NOT_ESTABLISHED`로 기록한다. 합성 시간·테스트 더블 호출 수에서 실제 사용자 정확도·지연·비용 우위를 주장하지 않는다.

실제 제보의 담당자 정답, 사진만 있는 제보의 브라우저 종단, 새로운 프로젝트에서의 실모델·검색 품질은 아직 검증하지 않았다. [사용법](../guides/knowledge-review.md)을 참고한다.
