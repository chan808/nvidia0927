# 게시 전 문서·파일 점검

2026-09-29. 최신 [서비스 확인 전체 검증](project-recovery.md)의 **689개 통과·실제 PostgreSQL 32개** 이후 문서와 게시 파일을 정리했다. 애플리케이션·검사 소스는 해당 검증의 해시와 일치하며 이번 정리로 동작을 변경하지 않았다.

## 정리한 항목

- 사용하지 않는 루트 `alembic.ini`를 제거했다. 마이그레이션은 `scripts.storage_admin`이 연결을 전달하고 `tracebridge.storage.migrations`가 내부 Alembic 경로를 지정하는 방식으로 실행한다. 과거 [초기 검증 메타데이터](postgres-rag.json)의 당시 파일 해시는 그대로 보존한다.
- 참조되지 않는 `output/independent-review-478db4531b/`의 검토 산출물 7개를 Git 추적에서 제외했다. 원 로컬 자료는 보존하며 기존 `output/` ignore 규칙을 적용한다. 사용·테스트·문서에서 참조하는 소스, fixture, 예전 검증 문서는 유지했다.
- 시작하기의 씨드 전용 안내를 실제 프로젝트 등록·검토 적용·적용 후 확인 흐름에 맞췄다.
- 검증 가이드가 최신 기록을 가리키도록 수정하고 PostgreSQL 전용 검사가 기본 실행에서 건너뛰어지는 조건과 격리 DB 설정을 명시했다.
- daily 연결에 별도 계측 소스가 필요하며 이 저장소의 연결 명령이 daily 소스를 설치·수정하지 않는다는 조건을 명시했다.

## 게시 파일 검증

로컬 Markdown 링크와 Python 문법, 알려진 credential 형식, 기존 689개 검사의 소스 해시를 점검했다. credential 점검의 예외는 해시로 고정된 기존 가짜 토큰 제거 테스트 fixture 하나이며 실제 값이 검토 로그에 나오지 않게 처리했다. 정리 뒤 저장소 계약·배포 묶음·서비스 준비 검사 **24개가 통과**했고 `pip check`도 통과했다.

네트워크 없이 별도 출력 폴더에서 wheel을 만들고 Python 소스 **53개**가 현재 파일 바이트와 일치함을 확인했다. Alembic 환경 파일과 마이그레이션 3개가 모두 포함된다. 새 환경 설치나 새 Linux 이미지 실행을 수행한 것으로 해석하지 않는다. 파일 수·링크 수·패키지 해시는 [기계 판독 기록](publication-review.json)에 있다.

## 저장소와 운영 범위

게시 대상은 현재 작업 저장소 `chan808/nvidia0927`의 `main`이다. 작업 중 수정한 별도 daily 파일 13개도 검증 당시 해시와 일치한다. daily에는 이번 작업 이전의 미푸시 커밋 39개와 기존 `frontend/next-env.d.ts` 변경이 있어 해당 작업 트리와 이력은 보존한다. 이번 TraceBridge 푸시는 daily의 `main` 게시나 AWS 자동 배포를 수행하지 않는다. daily의 실제 적용·회복 정책도 기존 비활성 상태를 유지한다.
