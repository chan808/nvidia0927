# 작업 운영·선택적 사건 RAG 검증

2026-09-29. Windows / Python 3.12. 기존 데이터 보존, 작업 큐·이력, 검토된 요약의 선택적 벡터 검색을 보완했다. [설정과 후속 개선](../guides/operational-hardening.md)을 함께 확인한다.

## 검증한 계약

| 영역 | 검증 |
| --- | --- |
| 작업 배분 | 소유자 P0~P3, 난이도별 45/90/180초 조사 예산, 실행 중 추가 배분 방지 |
| 취소·복구 | 취소 대기/확보 결과 미확인 작업이 다음 작업을 막음, 종료 확인 후 제외, 이전 임대의 늦은 결과 거부 |
| 영속 이력 | 접수·상태/평가 변경·모델 요청/완료/결과 미확인, 중복 모델 응답의 중복 이력 방지 |
| 기존 DB | 결과·입력 해시 보존, 과거 이력은 미기록으로 명시, 반복 초기화가 이력을 중복 생성하지 않음 |
| 실제 Streamlit 코드 | AppTest에서 우선순위 지정 접수, 새 세션의 작업 목록·결과·실행 이력 재열기 |
| 사건 검색 | 한국어 접두어, 서비스·환경·프로젝트·현재 사건 제외, 정확 지문 우선, 기존 검색 실패 분리 |
| 벡터 경계 | 승인/편집만 색인, 편집·반려 시 즉시 무효화, 색인 중 검토 변경 거부, 모델/차원/잘못된 벡터 분리 |
| 선택적 전송 | 제보별 외부 분석 동의가 없으면 서버 임베딩 미호출, 실행기 임의 검색 범위를 등록 범위로 대체 |
| API 전송 형식 | NIM passage/query 구분·응답 배열 인덱스·정규화, 네트워크는 명시적인 MockTransport |
| 평가 | 정답 카드/관련 사례 없음으로 Recall@2·MRR@2·오탐을 계산. 합성 임베딩 더블 결과임을 명시 |

## 실행 결과

최종 전체 회귀는 **579개 통과(108.56초)**다. 개인정보 저장 보완 이전 전체 회귀 **578개 통과(108.01초)**와 초기 전체 회귀 **575개 통과(106.83초)**도 단계별 기록으로 보존하며 합산하지 않는다. 소스 파일의 SHA256은 아래의 기계 판독 기록에 있다.

```powershell
.\.venv\Scripts\python.exe -m pytest -q -p no:cacheprovider --basetemp output/<새로운-검사-폴더> --tb=short tests
```

Windows의 기존 pytest 임시 폴더 접근 권한 문제로 새 검사 폴더에서 실행했다. 테스트는 별도 SQLite와 공개 합성 자료를 사용하며 실제 프로젝트 원본·운영 DB·외부 모델·임베딩 서비스를 수정/호출하지 않는다.

## 미검증과 제한

- 새 실제 브라우저 조작은 수행하지 않았다. 이번 화면 검증은 실제 Streamlit 코드를 실행하는 AppTest이며 [이전 GUI 검증](local-gui-final.md)과 구분한다.
- NIM 임베딩의 실서빙·한국어 유사도·비용, 실제 사건의 검색/원인/수정 품질 향상은 확인하지 않았다. 테스트 더블의 순위가 실제 모델의 품질을 증명하지 않는다.
- 벡터 조회는 범위 내 최대 500개를 읽는 정확 코사인 방식이다. 독립 Vector DB·ANN·리랭커 서비스·자동 중요도/난이도 추정·정책 자동 변경을 구현한 것으로 주장하지 않는다.
- 실제 daily 로그·실행 SHA, 실제 증상 재현 검사, 원본 적용 후 서비스 확인·자동 배포/복구는 후속 조건이다.
- 코드 변경은 저장소에 남겼다. 이미 실행 중인 웹·API·PC 실행기는 새 코드를 사용하도록 재시작해야 한다. 실제 운영 인스턴스를 이 검증에서 변경하지 않았다.

[기계 판독 검증 기록](operational-hardening.json)에 최종 결과와 파일 해시를 기록했다. SHA256은 이 PC의 로컬 파일 바이트이며 Git blob이나 다른 OS의 줄바꿈 변환 결과와 구분한다.
