# Linux CI·임대 재전송 재검증

2026-09-30. [Regression 워크플로](https://github.com/chan808/nvidia0927/actions/workflows/regression.yml)의 첫 두 실행이 로컬 Windows 검증에서 드러나지 않은 조건을 발견했다. 실패 원인을 수정하고 **전체 로컬 회귀 790개 통과(283.08초), 실패·오류·건너뛰기 0개**를 실제 PostgreSQL과 함께 확인했다. JUnit·소스 해시는 [메타데이터](ci-portability.json)에 기록한다. GitHub 실행의 최종 상태는 링크의 최신 커밋 결과를 확인한다.

| GitHub에서 드러난 조건 | 수정·검증 |
| --- | --- |
| Ubuntu의 간접 `boto3` 버전이 Windows 3.12.7 잠금 파일과 다름 | 프로젝트 직접 의존성의 고정 버전은 양쪽에서 검사하고 Windows 전용 잠금 버전 일치는 해당 Windows 환경에서만 검사. 파일 형식과 정확 버전 지정은 모든 환경에서 확인 |
| `Path.write_text`가 Linux에서는 LF, Windows에서는 CRLF로 저장됨 | 원본 적용 거절 전후의 실제 저장 바이트를 비교해 플랫폼별 개행에서도 새 편집이 보존되는지 확인 |
| 결과 커밋 중단 뒤 예전 임대의 갱신 실패가 새 작업까지 실패 처리 | 종료한 실행의 활성 임대를 비우고, 갱신 응답이 현재 활성 작업에 속할 때만 실패로 기록. 예전 갱신·현재 갱신을 분리한 결정적 검사와 중단 재전송 검사를 추가 |

첫 [GitHub 실행](https://github.com/chan808/nvidia0927/actions/runs/36663354922)은 의존성·개행 2건, 두 번째 [실행](https://github.com/chan808/nvidia0927/actions/runs/36663827544)은 임대 재전송 2건으로 실패했다. 이 실패 이력을 성공 기록으로 바꾸지 않는다. 수정 뒤 관련 검사 6개와 전체 790개가 로컬에서 통과했고 전용 PostgreSQL의 잔여 생성 DB 0개를 확인한 뒤 클러스터를 종료했다. 실제 서비스 장애 해결이나 실모델 품질의 증거는 아니다.

문서·묶음 갱신 뒤 제출 초안과 임대 경합 전용 4개 검사도 통과했다. 문서 링크 501개, Python 파일 132개, 설치된 의존성을 점검했다.
